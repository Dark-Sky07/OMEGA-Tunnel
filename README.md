# Omega VPS All In One Optimizer

بهینه‌سازی کامل، عمیق و همه‌جانبه سرورهای لینوکس (VPS) — **بدون نیاز به سرور داخلی (ایران)** — کاملاً هماهنگ و بدون کوچک‌ترین تداخل با پنل‌های فعال ۳ایکس‌یوآی (3x-ui / Omega Panel).

## قابلیت‌های کلیدی

- **BBR + FQ + تیونینگ عمیق sysctl:** افزایش چشم‌گیر پهنای‌باند و از بین بردن پکت‌لاس با الگوریتم FQ Pacing
- **رفع مشکل اپراتورهای سخت‌گیر (سامانتل، رایتل و شبکه موبایل):** مجهز به PMTU Clamping پویا بدون افت سرعت آپلود گوگل
- **بهینه‌ساز اختصاصی اینستاگرام و استریم ویدیو:** حذف لودینگ ریلزها با قابلیت Targeted QUIC Rejection بدون آسیب به وایرگارد و وارپ
- **سرعت حداکثری هوش مصنوعی و سرویس‌های گوگل (Gemini, Google Photos, Cloud):** بهینه‌سازی سایز بافرها برای آپلود سریع
- **منوی تعاملی تمام‌انگلیسی (`omega`):** بدون مشکل به‌هم‌ریختگی فونت فارسی در ترمینال سرور
- **آپدیت سیستم و نصب خودکار ابزارهای ضروری لینوکس**

## قرارداد عدمِ تداخل با پنل (Safety Contract)

این اسکریپت طوری طراحی شده که با پنل موجود **هیچ تداخلی نداشته باشد**:

| هرگز دست نمی‌زنیم | به‌جاش |
|---|---|
| `/etc/x-ui` و دیتابیس پنل | همه‌چیز در `/opt/omega-boost` |
| کانفیگ Xray پنل (`/usr/local/x-ui/bin/config.json`) | سرویس‌ها و ابزارهای جدا |
| باینری Xray پنل | دست‌نخورده باقی می‌مونه |
| ری‌استارت x-ui | هیچ مرحله‌ای ری‌استارت نمی‌خواد — کاربران آنلاین قطع نمی‌شن |
| اینباندهای فعلی | هر چیز جدید اضافه‌ست، نه جایگزین |
| وایرگارد و کلودفلر وارپ | کاملاً امن و محافظت‌شده |
| فایروال | فقط قانون‌های مشخص + قابلیت Rollback آنی |

## نصب و اجرای خودکار (One-Liner Installer)

روی سرور خود دستور زیر را اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/Dark-Sky07/OMEGA-Tunnel/arena/01a0d868-omega-tunnel/install.sh | bash
```

پس از نصب، در هر زمان با تایپ دستور ساده زیر می‌توانید منوی مدیریت را باز کنید:

```bash
omega
```

## قابلیت‌های منوی تعاملی (`omega`)

1. **Server Audit (Preflight):** بررسی پورت‌ها، منابع سرور و کشف تداخل‌ها (کاملاً فقط‌خواندنی)
2. **Network & Kernel Tuning:** فعال‌سازی BBR + FQ و بهینه‌سازی پارامترهای TCP لینوکس
3. **Operator Compatibility Booster:** حل تخصصی مشکل وصل نشدن سامانتل و رایتل با رفع تله MTU
4. **Instagram & Streaming Optimizer:** رفع کامل گیر و لودینگ ریلزهای اینستاگرام (کاملاً سازگار با وایرگارد)
5. **System Maintenance & Essential Tools:** آپدیت مخازن و نصب ابزارهای ضروری شبکه
6. **One-Click Full Server Optimization:** اعمال یک‌جای تمام بهینه‌سازی‌ها با یک کلیک
7. **VLESS-Reality Guide for Port 443:** راهنمای گام‌به‌گام تنظیم اینباند روی پورت آزاد ۴۴۳
8. **Connection & Diagnostics:** تست پینگ و پکت‌لاس به ایران و جهان
9. **Rollback & Restore:** بازگردانی سریع همه تغییرات به وضعیت اولیه
[u] **Update Suite:** آپدیت منو به آخرین نسخه با یک کلیک
