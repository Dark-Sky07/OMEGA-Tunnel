# OMEGA-Tunnel

بهینه‌سازی کیفیت اتصال کاربران ایرانی به سرورهای خارج — **بدون نیاز به سرور داخلی (ایران)** — برای سرورهایی که پنل ۳ایکس‌یوآی (3x-ui / Omega) روی‌شون نصبه.

## ایده اصلی

به‌جای خرید سرور ایران برای ریلی، کیفیت رو از سمت سرور خارج به حداکثر می‌رسونیم:

- **BBR + FQ + تیونینگ عمیق sysctl** — بهبود شفاف برای همه‌ی کاربران فعلی، بدون ری‌استارت پنل و بدون قطعی
- **سازگاری با تمام اپراتورها (سامانتل، رایتل، همراه‌اول، ایرانسل)** — حل مشکل Path MTU Blackhole و فریز در مرحله Handshake
- **استفاده از پورت طلایی 443** — استانداردترین پورت وب برای دور زدن فیلترینگ سخت‌گیرانه اپراتورهایی مثل سامانتل
- **منوی تعاملی تمام‌انگلیسی (`omega`)** — بدون مشکل به‌هم‌ریختگی حروف فارسی در ترمینال لینوکس
- **آپدیت سیستم و نصب ابزارهای ضروری** (curl, jq, sqlite3, htop, socat و...)

## قرارداد عدمِ تداخل با پنل (Safety Contract)

اسکریپت‌های این مخزن طوری طراحی شدن که با پنل 3x-ui موجود **هیچ تداخلی نداشته باشن**:

| هرگز دست نمی‌زنیم | به‌جاش |
|---|---|
| `/etc/x-ui` و دیتابیس پنل | همه‌چیز در `/opt/omega-boost` |
| کانفیگ Xray پنل (`/usr/local/x-ui/bin/config.json`) | سرویس‌ها و ابزارهای جدا |
| باینری Xray پنل | دست‌نخورده باقی می‌مونه |
| ری‌استارت x-ui | هیچ مرحله‌ای ری‌استارت نمی‌خواد — کاربران آنلاین قطع نمی‌شن |
| اینباندهای فعلی | هر چیز جدید اضافه‌ست، نه جایگزین |
| Flush فایروال | فقط قانون ACCEPT اضافه + اسنپ‌شات قبلی + rollback تمیز |

## نصب خودکار با یک دستور (One-Liner Installer)

روی سرور خود دستور زیر را اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/Dark-Sky07/OMEGA-Tunnel/arena/01a0d868-omega-tunnel/install.sh | bash
```

پس از نصب، در هر زمان با تایپ دستور ساده زیر می‌توانید منوی مدیریت را باز کنید:

```bash
omega
```

## قابلیت‌های منوی تعاملی (`omega`)

1. **Server Audit (Preflight):** بررسی پورت‌ها، منابع سرور و کشف تداخل‌ها (کاملاً فقط‌خواندنی)
2. **Network & Kernel Tuning:** فعال‌سازی BBR + FQ و بهینه‌سازی پارامترهای TCP لینوکس
3. **Operator Compatibility Booster:** حل تخصصی مشکل وصل نشدن سامانتل و رایتل با رفع گیربکس MTU/MSS
4. **System Maintenance & Essential Tools:** آپدیت مخازن و نصب ابزارهای ضروری شبکه
5. **One-Click Full Server Optimization:** اعمال یک‌جای تمام بهینه‌سازی‌ها با یک کلیک
6. **VLESS-Reality Guide for Port 443:** راهنمای گام‌به‌گام تنظیم اینباند روی پورت آزاد ۴۴۳
7. **Connection & Diagnostics:** تست پینگ و پکت‌لاس به ایران و جهان
8. **Rollback & Restore:** بازگردانی سریع همه تغییرات به وضعیت اولیه
